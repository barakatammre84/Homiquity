# Lender Demo Kit

Assets for pitching **wholesale / TPO lenders** to credential Homiquity as a broker.
Both tell the same **full end-to-end story**: *borrower → organized, standards-valid
MISMO package → delivered to a wholesale lender.*

| File | What it is | Use it for |
|---|---|---|
| `Homiquity_Lender_Demo.pptx` | 15-slide editable deck (Royal Blue Emerald brand) | Live pitch, screen-share, or leave-behind. Edit freely in PowerPoint / Keynote / Google Slides. |
| `video-walkthrough-script.md` | Shot-by-shot screen-capture script + storyboard (~5:45) | Record a Loom/OBS demo yourself — real routes, roles, narration, and capture notes are all specified. |
| `screenshots/` | (empty) | Drop real product captures here to embed in the deck / video. |

## Deck outline
Title · Problem · What we are (the core loop) · **The pipeline** · Acquire · Intake ·
Decide · **Package** · Dual AUS · Deliver · Why lenders win · Compliance & trust ·
Status (built vs. live) · **The ask** · Appendix.

## Honesty rails (baked into both — keep them if you edit)
- **Licensing is in progress** — the pitch is to be *credential-ready*. No NMLS number is
  shown anywhere; it prints only once issued.
- **Vendor legs (credit, DU/LPA, AVM, lender submission) are deterministic simulations
  behind production adapters** — presented as *built and validated, live on credentialing*,
  never as live vendor calls.
- The engine **validates**, it does not **approve**; **AI never decides.**
- Fannie Mae / NMLS terminology matches the official specs — nothing invented.

## Before you send / present — fill these in (flagged `TODO` in the files)
- **Contact block** on the deck's "ask" slide: founder name, phone. (Email/site are set:
  `support@homiquity.com` · `homiquity.com`.)
- **NMLS #** — leave blank until issued (the deck says so explicitly).
- Optional: swap in **real product screenshots** (run `pnpm dev`, capture the screens the
  video script lists, drop them in `screenshots/`).

## Regenerating the deck
The deck is generated by `build-deck.js` (pptxgenjs) — palette, layout, and copy are all in
that one file. Edit it and rebuild, or ask Claude to. From this folder:
```
npm install pptxgenjs react-icons react react-dom sharp   # one-time
node build-deck.js                                        # writes Homiquity_Lender_Demo.pptx
```
pptxgenjs writes an uncompressed zip; to shrink it, re-deflate the archive (any zip tool, or
have Claude run the recompress step). The file opens fine either way.
