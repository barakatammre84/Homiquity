# My Research

This directory is yours. Drop anything here: notes, questions, experiments,
vendor research, meeting notes, screenshots, half-formed ideas.

Suggested (not required) conventions:
- One markdown file per topic, dated in the name when useful, e.g.
  `2026-07-plaid-pricing-notes.md`.
- Keep a running `questions.md` of things you don't understand yet — great
  fodder for asking Claude or a future teammate.
- Nothing here is load-bearing for the app; it's safe to reorganize anytime.
