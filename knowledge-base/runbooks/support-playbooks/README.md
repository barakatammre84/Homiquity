# Support Playbooks

Rehearsal assets for the Customer Success function. **There are no live borrowers on Homiquity yet** — every playbook here is written and drilled ahead of need, not in response to real tickets. Do not read anything in this directory as evidence of actual support volume or incidents.

Each playbook: trigger → first response (exact copy) → what to check in the app → escalation line → the compliance rail it must never cross.

Rotation (one drafted/refreshed per day):
- (a) Locked-out user — [locked-out-user.md](./locked-out-user.md)
- (b) Document rejected/low-confidence
- (c) Adverse Action Notice questions
- (d) Maintenance/INTAKE_PAUSED response
- (e) Privacy/data request (GLBA + state privacy)
- (f) Rate/pricing questions

Standing cross-cutting playbook (not part of the daily rotation — kept current whenever the underlying code changes):
- [discrimination-credit-error-escalation.md](./discrimination-credit-error-escalation.md) — the mandatory immediate-escalation path for any complaint alleging discrimination or a credit-reporting error.

Legally sensitive copy (anything touching denials, disputes, or discrimination) carries a ⛔ founder/legal signoff requirement before use with a real borrower — see the marker in each file.
